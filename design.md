# SmartCampus AI — Design System

## 1. Design Vision
A premium university SaaS interface combining institutional trust with modern AI-product aesthetics.

## 2. Visual Language
- Primary theme: light
- Background: white and soft neutral gray
- Primary accent: blue
- AI accent: blue/purple gradient used selectively
- Text: dark navy/charcoal
- Borders: subtle neutral
- Cards: rounded, clean, lightly elevated
- Typography: modern sans-serif
- Icons: simple consistent line icons

Do not use excessive gradients, neon colors, heavy glass effects, or decorative clutter.

## 3. Layout
Desktop:
- Persistent sidebar
- Top header
- Main content area
- Responsive grid

Mobile:
- Collapsible navigation or bottom navigation
- Stacked cards
- Responsive tables
- Touch-friendly controls

## 4. Navigation
Student:
Dashboard / Submit Complaint / My Complaints / Notifications / Messages / Feedback / Profile / Settings

Staff:
Overview / Assigned Complaints / All Complaints / Urgent Issues / Messages / Reports / Profile / Settings

Admin:
Overview / Complaints / Analytics / Departments / Users / Reports / Settings

## 5. Components
Create reusable:
- Buttons
- Inputs
- Selects
- Cards
- Tables
- Tabs
- Modals
- Drawers
- Badges
- Alerts
- Toasts
- Charts
- Timelines
- Progress indicators
- Avatars
- File uploaders
- AI insight cards

## 6. Status System
Pending, Under Review, Assigned, In Progress, Resolution Submitted, Resolved, Closed.

Priority:
Low, Medium, High, Critical.

Use icons + labels + color, never color alone.

## 7. AI Components
AI analysis card should show:
- AI icon
- Category
- Urgency
- Suggested department
- Confidence
- Summary
- Suggested action
- Review/edit controls

## 8. Dashboard Design
Use KPI cards at the top, followed by charts, AI insights, urgent items, and recent activity.

Avoid excessive charts. Every chart should communicate a useful operational metric.

## 9. Interaction Design
Use subtle hover/focus states and short transitions. Important actions should provide immediate feedback. Destructive actions require confirmation.

## 10. Forms
Keep forms grouped into logical sections. Use inline validation and helpful examples. Show upload limits and accepted formats.

## 11. Empty/Error/Loading States
Every data-driven screen needs:
- Loading skeleton
- Empty state
- Error state
- Retry/recovery action

## 12. Brand
Name: SmartCampus AI
Tagline: Smarter Complaints. Faster Resolution. Better Campus.
Tone: professional, helpful, transparent, intelligent, trustworthy.
